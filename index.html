ตั้งค่าเชื่อมต่อ Google Sheet & Google Drive (ออนไลน์)

บันทึกข้อมูลลง Google Sheet และเก็บรูปถ่าย 2-3 รูปลงโฟลเดอร์ Google Drive อัตโนมัติ

สถานะ: รอระบุ Web App URL ในโค้ด
วาง Web App URL ด้านล่าง หรือกำหนดในตัวแปร CLOUD_CONFIG.DEFAULT_GAS_WEBAPP_URL

* นำ URL ที่ได้จากการกด Deploy > New deployment (Web app) ใน Google Sheet มาวางที่นี่

หากต้องการระบุโฟลเดอร์เอง ให้คัดลอกรหัสท้ายลิงก์โฟลเดอร์ Google Drive เช่น 1aBcDeFgHiJkLmNoPqRsTuVwXyZ มาใส่

ฝังค่าการเชื่อมต่อลงในโค้ด (Hardcode ลงไฟล์ index.html โดยตรง)
ไม่ต้องตั้งค่าซ้ำเมื่อเปิดเครื่องอื่น

เมื่อกรอก Web App URL ด้านบนแล้ว คุณสามารถกดปุ่มด้านล่างเพื่อคัดลอกโค้ด HTML หรือดาวน์โหลดไฟล์ index.html ที่ฝัง URL ลงในตัวแปร CLOUD_CONFIG ในโค้ดให้เรียบร้อยแล้วได้ทันที

เมื่อเชื่อมต่อแล้ว ทุกครั้งที่กด "บันทึกข้อมูล" รูปทั้ง 2-3 รูปจะถูกอัปโหลดเข้า Google Drive ทันที
1 เตรียม Google Sheet & Apps Script
  1. สร้างไฟล์ Google Sheet ใหม่ใน Google Drive ของคุณ
  2. ไปที่เมนูด้านบน ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมในไฟล์ Code.gs ออกทั้งหมด แล้วกดปุ่ม "คัดลอกโค้ด Code.gs" ด้านล่างไปวางแทนที่ จากนั้นกดบันทึก (💾)
2 การ Deploy เพื่อรับ Web App URL
  1. มุมขวาบนของ Apps Script กดปุ่ม การทำให้ใช้งานได้ (Deploy) > รายการใหม่ (New deployment)
  2. คลิกไอคอนฟันเฟือง เลือกประเภทเป็น เว็บแอป (Web app)
  3. ช่อง Execute as (ดำเนินการในฐานะ) เลือก Me (ฉัน)
  4. ช่อง Who has access (ผู้ที่มีสิทธิ์เข้าถึง) เลือก Anyone (ทุกคน) แล้วกด Deploy > กดอนุญาตสิทธิ์ (Authorize access)
  5. คัดลอก Web App URL ที่ได้ นำมาวางในแท็บที่ 1 ของหน้าต่างนี้!
3 ทางเลือกในการนำหน้าเว็บขึ้นออนไลน์ (ให้ทีมงานเปิดใช้ผ่านมือถือ/คอมได้ทุกที่)
  • วิธีที่ A (แนะนำ - ฟรีและเร็วที่สุด): อัปโหลดไฟล์ index.html นี้ขึ้นเว็บโฮสติ้งฟรี เช่น GitHub Pages, Netlify Drop (ลากโฟลเดอร์วางที่ app.netlify.com/drop), หรือ Vercel แล้วนำ Web App URL มาตั้งค่า
  • วิธีที่ B (รันบน Google Apps Script โดยตรง): ในหน้าต่าง Apps Script เดียวกัน กดปุ่ม + (เพิ่มไฟล์) > HTML ตั้งชื่อว่า index (ไม่ต้องมี .html) แล้วคัดลอกโค้ด HTML ของหน้านี้ทั้งหมดไปวาง จากนั้นเปิดลิงก์ Web App URL เพื่อใช้งานได้ทันที
